# Maraton Raidów — NosTale (Olympus)

Narzędzie do układania składów na maratony rajdów: przypisuje graczy do ról według SP, PSP (PRI / SEC / ELE / dodatkowe), żywiołów i zadań (dźwignie, BA, portal), prowadzi maraton na żywo (top 3 z każdego rajdu) i buduje bazę graczy.

**Strona:** https://czeresniaqu-svg.github.io/maratony/

- Działa w przeglądarce, bez instalacji. Dane (gracze, historia) zapisują się lokalnie w przeglądarce każdej osoby.
- Dzielenie się historią: *Zapis / Import → Eksportuj do pliku*, a druga osoba *Import → Połącz z moimi danymi*.
- Język: przełącznik PL / EN w prawym górnym rogu.

Raid team builder for NosTale raid marathons — assigns players to roles by SP, PSP, element and tasks, runs a live marathon (top 3 per raid) and keeps a player database. Runs in the browser; data stays in each user's browser.
